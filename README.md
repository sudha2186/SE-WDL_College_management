# College Event Management System

## Project Overview

The **College Event Management System** is a front-end web application developed as a mini project to manage college events efficiently. The system provides a platform where students can view upcoming events, register for events, and access their dashboard after successful login.

The project demonstrates the use of **HTML, CSS, Bootstrap, and JavaScript** for developing responsive static web pages with client-side form validation and user interaction.

---

## Features

### Student Features

- Responsive Home page with event information
- View upcoming college events
- Student registration form
- Client-side form validation
- Secure login authentication
- Personalized dashboard
- View registered event details
- Logout functionality

### Organizer Dashboard

- Login-based dashboard access
- Display user information
- View event statistics
- Upcoming event listing
- Responsive dashboard interface
